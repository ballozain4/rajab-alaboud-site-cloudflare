# دليل لوحة المحتوى المحلية

هذه اللوحة تعدّل المحتوى العام للموقع فقط. لا تعرض طلبات الاستشارة ولا أسرار Cloudflare ولا قاعدة D1.

## بدء العمل

من مجلد المشروع:

```bash
npm ci
npm run dashboard
```

ثم افتح:

```text
http://127.0.0.1:4321/local-dashboard/
```

اللوحة لا تعمل على رابط Cloudflare العام.

## طريقة الحفظ والنشر

1. عدّل الحقول المطلوبة.
2. استخدم المعاينة للتحقق من النتيجة.
3. اضغط «حفظ في ملفات المشروع».
4. شغّل `npm test` ثم `npm run build`.
5. راجع التغييرات في Git.
6. أنشئ Commit وادفعه إلى GitHub.
7. ينشر Cloudflare Workers التغيير تلقائياً إذا كان المستودع مربوطاً بخدمة Builds.

## تخصيص الحقول مباشرة داخل البطاقات والأقسام

لا يوجد تبويب منفصل لحقول الخدمات. داخل كل خدمة أو حالة من معرض الأعمال أو إنجاز أو قسم أو عنصر صفحة:

- تعديل عنوان أي حقل أساسي، مثل تغيير «لمن قد تناسب» إلى «الفئة المستهدفة».
- اضغط زر القلم بجانب عنوان الحقل لفتح نافذة التعديل السريع.
- تغيير ترتيب الحقول بالسحب والإفلات أو بواسطة السهمين.
- اختيار ظهوره في البطاقة أو نافذة التفاصيل.
- إخفاؤه عن الزائر أو جعله إلزامياً في العنصر الحالي.
- إضافة حقل جديد خاص بالعنصر الحالي وإدخال قيمته فوراً.

لا ينتقل تعديل التسمية أو الترتيب أو الإضافة إلى البطاقات الأخرى. المعرّف الداخلي ثابت ولا يحتاج إلى تعديل؛ ثباته يحمي القيمة المحفوظة عند تغيير العنوان الظاهر.

## تخصيص نموذج الاستشارة

من تبويب «نموذج طلب الاستشارة» يمكنك:

- تعديل عنوان الحقل والنص الإرشادي والملاحظة المساعدة.
- إضافة حقول نصية أو نص طويل أو هاتف أو قائمة اختيار أو مربع موافقة.
- تغيير الترتيب والعرض الكامل والظهور والإلزامية.
- تعديل خيارات حقول القوائم، بحيث يكون كل خيار في سطر.
- حذف الحقول الإضافية التي أنشأتها.

الهاتف وموافقة الخصوصية محميان ويظلان ظاهرين وإلزاميين. أُلغي حقل «أفضل وقت للتواصل»، وأصبح «وصف مختصر» اختيارياً.

## الدعوة الختامية

قسم `home-cta` باقٍ داخل منشئ الصفحات لكنه مخفي عن الموقع العام. يمكن إعادة إظهاره مستقبلاً بتفعيل خيار الظهور ثم حفظ ملفات المشروع.

## ترتيب الخدمات والحالات

- أمسك المقبض `⋮⋮` واسحب البطاقة إلى موقعها الجديد.
- على الهاتف أو عند استخدام لوحة المفاتيح استخدم السهمين ↑ و↓.
- اضغط «حفظ في ملفات المشروع» لاعتماد الترتيب.
- تُحفظ قيمة `order` داخل الملف؛ لذلك لا يعود العنصر إلى ترتيبه القديم بعد البناء.
- عند استخدام مربع البحث يُفضّل مسحه قبل إعادة ترتيب قائمة كبيرة حتى ترى جميع المواقع بوضوح.

## صور الخدمات والحالات

الصيغ المسموحة:

- JPG.
- PNG.
- WebP.
- AVIF.

الحد الأقصى للصورة 5 ميغابايت. الصورة المختارة تبقى في المعاينة إلى أن تضغط زر الحفظ.

لكل خدمة يمكنك اختيار صورة أو أيقونة. لكل حالة يمكنك اختيار:

1. قبل وبعد.
2. صورة نهائية واحدة.
3. قبل وبعد مع صور إضافية داخل التفاصيل.

النمط الثالث يبدأ بخانة إضافية واحدة، ويمكن زيادتها حتى 20 صورة. لا تظهر الخانات الفارغة للزائر.

## المسودات والنشر

- الحالة «مسودة» لا تظهر للزوار.
- الحالة «منشورة» تظهر إذا كان خيار «ظاهرة» مفعلاً.
- وسم «حالة تجريبية» يوضح أن الصور أو البيانات ليست نتيجة حقيقية.
- لا تنشر صور أشخاص قبل الحصول على موافقة صريحة وإزالة أي معلومات تعريفية غير لازمة.

## أماكن العمل

أضف اسم كل مركز في سطر مستقل ضمن «بيانات رجب العبود». إذا بقيت القائمة فارغة فلن يظهر سطر أماكن العمل في الموقع.

## المسودة المحلية

زر «حفظ مسودة محلية» يستخدم Local Storage على الجهاز الحالي. لا يغير ملفات المشروع ولا يرفع شيئاً إلى GitHub. الصور الجديدة المختارة لا يمكن استعادتها من المسودة وحدها، لذا استخدم حفظ الملفات لاعتمادها.

## ما لا تعدله اللوحة

- طلبات الاستشارة في D1.
- كلمة مرور `/admin/`.
- مفاتيح Turnstile.
- متغيرات Cloudflare.
- قواعد الحماية وحد الإرسال.
- منطق API.

هذه العناصر تحتاج مراجعة مطور وتغييراً منفصلاً.
